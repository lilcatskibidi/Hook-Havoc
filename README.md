# 🎣 Hook & Havoc

> **The ocean was supposed to be your fishing spot... not a battlefield.**

**Hook & Havoc** is a 2D top-down HTML game where you play as a fisherman trying to catch fish using a gun.

But there's a problem...

**THE FISH FIGHT BACK. 🐟🔫**

## 🎮 About the Game

Dive into a chaotic ocean where fishing isn't as peaceful as it sounds.

Move around the sea, aim your weapon, and hunt down fish to earn rewards. But watch out — the fish aren't going to just sit there and let you catch them.

Survive their attacks, catch as many fish as possible, and become the ultimate fisherman.

## ✨ Features

- 🎣 Fish and hunt different types of fish
- 🔫 Gun-based combat
- 🐟 Fish that attack the player
- 🌊 2D top-down ocean gameplay
- 💰 Catch fish and earn rewards
- ⚔️ Increasingly dangerous enemies
- 🕹️ Simple keyboard and mouse controls
- 🌐 Runs directly in your web browser

## 🕹️ Controls

| Key | Action |
|---|---|
| `WASD` | Move |
| `Mouse` | Aim |
| `Left Click` | Shoot |
| `R` | Reload |

> Controls may change as development continues.
